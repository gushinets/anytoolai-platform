# Артефакты замеров Freelancer Suite

Ревизия `452b879c3f8a1d9b57a18c151af6a607e9eb4b57`. Замеры выполнены через отдельный
локальный Atom Lab. Калибровка использовала одного worker. Остальная атомная серия
использовала до четырёх worker с предварительным резервом на все вызовы очередной группы.

95% интервала Wilson — около 44%. Вывод о выборе модели предварительный.

сохранило 59/90 годных. `fallback-analysis.json` содержит три сравниваемых режима.

## Полные сценарии и бюджет

Каждый сценарий использовал реальные промежуточные ответы и условные шаги.
В выборке по одной паре RU/EN из каждого из восьми сценариев пяти продуктов.
При расчёте общей экономики всем строкам дан одинаковый вес.

| Конфигурация | Годные конечные результаты | Критические | USD за годный сценарий | p50 / p95, с |
| --- | ---: | ---: | ---: | ---: |
| GPT-6.2 Sol / high | 16/16 | 0 | 0,01528–0,03064 | 11,5 / 47,7 |
| GPT-6.1 Sol / high | 15/16 | 1 | 0,01621 | 15,4 / 76,6 |
| GPT-5.6 Luna / medium | 10/16 | 1 | 0,00241–0,00519 | 8,8 / 29,8 |

Предварительный основной выбор — GPT-6.2 Sol / high по качеству свежих
атомных ответов и конечных сценариев. GPT-6.1 Sol / high — следующий кандидат.
GPT-5.6 Luna / medium — кандидат для случаев с приоритетом себестоимости и
готовностью проверять результат. Одна критическая ошибка GPT-6.2 Sol на
holdout касалась подмены пожелания обязательством в Acceptance Builder.

В обоих вариантах, где возникла неизвестная стоимость, неудачная
транспортная попытка в EN-черновике Acceptance Builder записана с нулём и
без счётчиков. Верхняя граница использует токенный потолок одной попытки.
Интервал сценарной стоимости GPT-6.2 Sol перекрывает цену GPT-6.1 Sol.

В общий бюджет вошли 926 атомных и 49 сценарных запусков, 1 034 физических
вызова. Расходы по PostgreSQL и пересчёту известного usage — $8,94109443.
Верхняя оценка с двумя неизвестными попытками — $9,21470723 из $20.
Резерв на ещё не завершённую работу — $0. Дополнительных платных вызовов
оценщика — 0.

Первый сценарный запуск дождался исправления окончания строки в маркере
активации worker на Windows. Его $0,00473177 и четыре физических вызова
вошли в бюджет. Для оценки качества и времени использован сопоставимый
повтор с тем же входом. Один атомный замер восстановлен после разрыва
соединения с PostgreSQL, время этой строки взято из Atom Lab timestamps.
Локальная сборка ограничивала одну генерацию 16 384 выходными токенами
включая reasoning. Во всей серии не было ответов с причиной остановки
`length`.

Продуктовое покрытие составило 15 промптов на восьми атомах. A03, A08 и A09
в этой ревизии представлены платформенными примерами.
