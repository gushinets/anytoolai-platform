# Пересмотр отказов по пригодности ответа для клиента

Пересмотр от 25 ноября 2026 года по сохранённым входам и выходам серии 01. Из 926 атомных запусков и 48 сопоставимых полных сценариев исходная оценка отклонила 242 результата. У одного запуска отсутствует валидный ответ. У остальных 241 заново сопоставлены вход, результат, исходная причина отказа и пользовательские критерии. Уже принятые ответы сохранили изначальную оценку. В отчёт входят повторы, RU/EN и разные модели на общих кейсах. Числа обозначают ответы, а не количество уникальных заказов.

Михаил лично оценил четыре примера. Остальные выводы — перенос его критериев на аналогичные ответы. Проверяющие работали с записями по слепым идентификаторам; модели присоединены при агрегации. Проверка оценивает готовность для пользователя. Формальное несоответствие исходной технической рубрике сохранено в журнале. При оценке промежуточных структур также учитывалось, какие значения попадут в последующие шаги и на экран.

| Новое решение при исходном отказе | Ответов | Как отражается в метрике |
|---|---:|---|
| Готов без правок (`send`) | 49 | Включён в стоимость готового ответа |
| Только редакторская правка (`edit`) | 21 | Учтён отдельно в показателе «готов или требует редактуры» |
| Нужна содержательная правка (`fail`) | 125 | Остаётся отклонённым |
| Зависит от дополнительного решения владельца продукта (`unknown`) | 46 | Остаётся вне зачёта |
| Технический сбой (`technical`) | 1 | Учитываются затраты и попытка |

Включая известные примеры с авансом и словом *deliverables*, по первым двум категориям получились 70 ответов из 241. Сверх этих двух примеров — 48 готовых ответов и 20 с поверхностной правкой. Из спорных 18 относятся к одному заданию с сертификатами и трактовке статуса частичной сдачи. Ещё 10 относятся к заказу на перенос магазина с WooCommerce на Shopify и достаточности явного указания исходной платформы в отклике.

В пилоте на 540 запусках число готовых ответов выросло с 371 до 403, после поверхностной редактуры пригодны ещё 13. На свежих 90 входах низкая себестоимость Luna сочетается с сильной зависимостью от промпта. Её напоминания об авансе выросли с 2/6 до 6/6, включая два условных расчёта по ещё открытой цене, которые при пересмотре сочтены пригодными. Сравнение договорённостей в Acceptance Builder осталось на 1/6, ещё один ответ можно отредактировать. В резюме Brief Decoder 1/6 готов и ещё 5/6 требуют только оформления списка. Пригодность условных расчётов на сегодня является суждением повторной оценки; если сохранить для них исходный отказ, напоминания об авансе дадут 4/6, а общий результат Luna — 65/90.

Прямое сравнение GPT-6.2 Sol medium и high по тем же 18 входам даёт соответственно 15/18 и 17/18 готовых, USD 0,00556 и 0,01088 за ответ. Весь чистый прирост сосредоточен в русской приёмке. На полном наборе из 90 свежих входов режим medium этой модели не измерялся. Для цели 95% по каждому промпту и языку трёх свежих входов в ячейке недостаточно. Расходы взяты из исходного журнала, включая неуспешные попытки. Интервалы в полных сценариях отражают две попытки с неизвестным биллингом. Стоимость труда редактора в расчёты не входит.
