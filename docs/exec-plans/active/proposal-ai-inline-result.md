**Цель:** после генерации сохранять на экране описание задачи, опыт и тон рядом с предложением; дать исправить данные и пересоставить текст без перехода.

**Решение:** только Proposal AI включает двухколоночный режим существующего `ProductRunPage`. Общий сценарий запуска, повтора, квоты и копирования остаётся в нём. Последний успешный результат хранится вместе со снимком входных данных и виден до готовности следующего.

**Проверка исходной реализации:** тест с генерацией, редактированием, повторной генерацией и очисткой; lint, TypeScript, 278 веб-тестов и production build; ручная проверка на широком и узком экране локального сайта и один реальный запуск через провайдера. Оба поля ввода растягиваются по вертикали; кнопки копирования и новой задачи стоят рядом и переносятся при нехватке ширины. После последних замечаний локально прошли 281 веб-тест, TypeScript для web и proposal-ai-smoke, lint изменённых тестов и validate-docs. E2E smoke и полный CI после этого исправления ещё не подтверждены.
